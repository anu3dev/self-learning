# 🎂 Happy Birthday — Interactive Website

A multi-slide, animated birthday experience built with React + Framer Motion.

## Running it

```bash
npm install --legacy-peer-deps
npm run dev
```

Then open **http://localhost:5173**

---

## 📸 Adding Her Photos

Drop her photos into:

```
src/assets/images/
  1.jpg   ← "The smile that started everything"
  2.jpg   ← "Those eyes…"
  3.jpg   ← "That nose 😘"
  4.jpg   ← "Radiant"
  5.jpg   ← "Pure joy"
  6.jpg   ← "Grace"
  7.jpg   ← "Timeless"
  8.jpg   ← "Us — soon"
```

Any `.jpg` you drop there will show up in the gallery slide.
Missing ones show a beautiful placeholder automatically — no errors.

## 🎬 Slides

| # | Slide | Description |
|---|-------|-------------|
| 1 | **Intro** | Animated title, 30-year ring, floating petals |
| 2 | **Envelope** | Tap to open a wax-sealed letter |
| 3 | **Poem** | 6-stanza poem you wrote, one at a time |
| 4 | **Shayari** | 8 romantic shayaris — Hindi & English mix |
| 5 | **Gallery** | Photo grid with lightbox viewer |
| 6 | **Cake** | Tap to blow out 5 candles → confetti! |
| 7 | **Final Promise** | The closing love note + promises |

Navigation dots at the top let you jump to any slide.
