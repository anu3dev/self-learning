# Amazon Bedrock AgentCore

## What is Amazon Bedrock AgentCore?

**Amazon Bedrock AgentCore** is a complete set of services to **deploy and operate highly effective AI agents** using **any framework and model**.

Developers can use AgentCore's **modular, composable building blocks** together or independently to quickly and securely:

- Build AI agents
- Deploy AI agents
- Run AI agents
- Operate AI agents
- Scale AI agents

AgentCore provides **enterprise security controls** for production AI agents without requiring developers to build the underlying infrastructure from scratch.

---

## Core Concept

AgentCore provides a collection of **modular and composable building blocks** for AI agents.

These building blocks can be used:

- **Together** to create a complete AI agent solution
- **Independently** when only a specific capability is required

```text
Amazon Bedrock AgentCore

          |

          ├── Building Block
          ├── Building Block
          ├── Building Block
          └── Building Block

                   |

                   v

              AI Agent
```

## Why AgentCore?

Building and operating AI agents in production requires more than just the agent logic.

Organizations also need infrastructure for:

- Deployment
- Runtime
- Security
- Scaling
- Operations

Without a managed platform, developers would need to build and maintain much of this infrastructure themselves.
