# Kiro — Spec-Driven Development

## Overview

**Spec-Driven Development (SDD)** is the development approach used by Kiro to help developers move from a high-level idea to a structured implementation plan.

Instead of immediately asking AI to generate code, Kiro first helps define:

```text
Idea
  ↓
Requirements
  ↓
Design
  ↓
Tasks
  ↓
Implementation
```
