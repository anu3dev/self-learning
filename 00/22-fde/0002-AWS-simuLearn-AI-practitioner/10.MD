# AWS SimuLearn — Use AI Services with Amazon SageMaker

## Use Case

A global consulting firm processes more than **10,000 multilingual client communications and documents daily**.

### Problem

The current manual process:

- Costs approximately **$1.5M annually**
- Has a **15% error rate**
- Requires **20+ full-time employees**
- Can take up to **48 hours per document**

The company wants an automated solution that:

- Reduces operational costs
- Improves accuracy
- Decreases document processing time
- Supports multilingual client communications
- Improves global client service delivery

---

## Solution / Exercise

The solution uses **Amazon SageMaker AI** to combine multiple AWS AI services into an automated **text and speech processing pipeline**.

The SageMaker environment uses a **Notebook** to orchestrate the different AI services.

### High-Level Flow

```text
User
  ↓
Amazon SageMaker AI
  ↓
Notebook
  │
  ├── Amazon Polly
  │
  ├── Amazon Textract
  │       ↓
  │    Amazon S3
  │       ↕
  │    PDF Document
  │
  ├── Amazon Comprehend
  │
  ├── Amazon Transcribe
  │
  └── Amazon Translate
```

The **Notebook** acts as the central point for calling the different AWS AI services.

---

## Services Used

| AWS Service | Purpose |
|---|---|
| **Amazon SageMaker AI** | Provides the environment for building and orchestrating the AI processing pipeline |
| **Notebook** | Used to execute code and connect the different AI services |
| **Amazon Textract** | Extracts text/data from documents such as PDFs |
| **Amazon S3** | Stores the PDF documents |
| **Amazon Polly** | Converts text into speech |
| **Amazon Comprehend** | Analyzes and understands text |
| **Amazon Transcribe** | Converts speech/audio into text |
| **Amazon Translate** | Translates text between languages |

```text

     ↓

     ↓
```

## Key Learning

The main concept of this SimuLearn exercise is that **Amazon SageMaker AI can be used as an environment to combine multiple AWS AI services into a single processing pipeline**.

Instead of building every AI capability from scratch, the solution can use specialized managed AI services:

```text
Document Processing → Textract
Text Analysis       → Comprehend
Translation         → Translate
Speech → Text       → Transcribe
Text → Speech       → Polly
Storage             → S3
Orchestration       → SageMaker AI / Notebook
```
