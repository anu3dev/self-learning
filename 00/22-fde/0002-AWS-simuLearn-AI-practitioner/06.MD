# AWS SimuLearn — SageMaker Studio + Amazon Bedrock

## Use Case

**AnyCompany Software** wants to empower its staff to learn **prompt engineering techniques for Generative AI**.

### Problem

The company wants to improve:

- Software development speed
- Software quality
- Employee productivity
- Prompt engineering skills
- Ability to experiment with foundation models

They want users of different skill levels to experiment with Generative AI **without managing infrastructure**.

---

## Solution / Exercise

This solution pairs **Amazon SageMaker Studio** with **Amazon Bedrock**.

Users can use **SageMaker Studio and JupyterLab** to experiment with foundation models available through Amazon Bedrock.

In this exercise, the **DeepSeek-R1 foundation model** was used to experiment with prompt engineering.

### High-Level Flow

```text
User
  ↓
Amazon SageMaker Studio
  ↓
JupyterLab
  ↓
Amazon Bedrock
  ↓
DeepSeek-R1 Foundation Model
  ↓
Model Response
```

The model can be invoked using the **Amazon Bedrock Converse API**.

Prompts can also be saved and managed using **Amazon Bedrock Prompt Management**.

## Key Learning

This exercise demonstrates how **SageMaker Studio and Amazon Bedrock can work together** to allow users to experiment with foundation models and prompt engineering **without managing the underlying infrastructure**.

The exercise also covers different prompt engineering techniques.

### Zero-Shot Prompting

The model is given a task **without any examples**.

```text
Instruction
     ↓
Foundation Model
     ↓
Response
```

**Zero-Shot = 0 examples**

### One-Shot Prompting

The model is given **one example** before the actual task.

```text
Example
   ↓
Instruction
   ↓
Foundation Model
   ↓
Response
```

**One-Shot = 1 example**

### Few-Shot Prompting

The model is given **multiple examples** before the actual task.

```text
Example 1
Example 2
Example 3
      ↓
Instruction
      ↓
Foundation Model
      ↓
Response
```

The exercise includes creating a **few-shot prompt to classify customer sentiment**.

**Few-Shot = Multiple examples**

## AWS SimuLearn

**AWS SimuLearn** provides scenario-based, hands-on learning using realistic business problems.

The typical flow is:

```text
Business Scenario
      ↓
Design Solution
      ↓
Discuss Solution with AI
      ↓
Build Solution in AWS Console
      ↓
Validate Solution
```

It combines **Generative AI-based simulation** with **hands-on AWS Console exercises**.
