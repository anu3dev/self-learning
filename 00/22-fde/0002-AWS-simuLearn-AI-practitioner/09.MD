# AWS SimuLearn — Enterprise HR Knowledge Assistant

## Use Case

The **HR department** is struggling to respond to more than **500 employee requests per day**.

Most requests are related to:

- HR policies
- Employee benefits
- Procedures

The current solution has limitations:

- Requests can only be handled during business hours.
- The number of simultaneous responses is limited.
- HR needs an automated and scalable solution.

### Goal

Build an **AI-powered HR assistant** that can respond to employee requests using enterprise knowledge and perform specific HR actions when required.

---

## Solution

The solution uses **Amazon Bedrock AgentCore**, a **Knowledge Base**, **Amazon S3**, **AWS Lambda**, and **Amazon DynamoDB**.

The architecture allows the AI agent to:

1. Receive employee requests through a web application.
2. Retrieve information from an enterprise knowledge base.
3. Invoke actions when required.
4. Store action-related data in DynamoDB.
5. Return the response to the employee.

## Request Flow

### 1. Employee Request

An employee accesses the **web application** and sends a request.

```text
Employee
   ↓
Web Application
   ↓
AgentCore Runtime
```

---

### 2. AgentCore Runtime

**Amazon Bedrock AgentCore Runtime** receives the request and determines how it should be handled.

The request may require:

- Retrieving information from the knowledge base
- Invoking an action through the AgentCore Gateway

---

### 3. Knowledge Retrieval — RAG

For questions about HR policies, benefits, or procedures, the agent can make a **RAG request** to the Knowledge Base.

```text
Employee Question
      ↓
AgentCore Runtime
      ↓
Knowledge Base
      ↓
S3 Knowledge Base Data
      ↓
Relevant Information
      ↓
Agent Response
```

This allows the assistant to answer questions using enterprise HR information.

## Key Learning

This architecture demonstrates an **enterprise AI agent** that combines:

```text
Knowledge Retrieval
       +
Tool / Action Invocation
       +
Data Storage
       ↓
Enterprise AI Assistant
```

The assistant is not limited to answering questions.

It can:

- **Retrieve information** using RAG.
- **Invoke actions** through AgentCore Gateway.
- **Execute business logic** using Lambda.
- **Store action data** in DynamoDB.

---

## RAG vs Action

An important distinction in this architecture is:

### RAG

Used when the agent needs to **retrieve information**.

```text
Question
   ↓
Knowledge Base
   ↓
S3
   ↓
Relevant Information
   ↓
Answer
```

Example:

> "What is our employee benefits policy?"

---

### Action

Used when the agent needs to **perform an operation**.

```text
Employee Request
      ↓
AgentCore Runtime
      ↓
AgentCore Gateway
      ↓
Lambda
      ↓
DynamoDB
```

Example:

> "Submit my leave request."
