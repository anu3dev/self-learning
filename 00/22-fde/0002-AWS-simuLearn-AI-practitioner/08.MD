# AWS SimuLearn — Create an Enterprise Knowledge Assistant

## Use Case

The **Sales department** lacks quick access to historical and current sales data.

This leads to:

- Inconsistent answers to similar sales queries
- Difficulty retrieving accurate product performance information
- Slower decision-making

Sales representatives need a reliable way to quickly retrieve accurate information about **product performance trends** and provide **data-driven recommendations** to upper management.

## RAG — Core Concept

**Retrieval-Augmented Generation (RAG)** allows a foundation model to use relevant information retrieved from an external knowledge source when generating a response.

```text
User Question
      ↓
Retrieve Relevant Information
      ↓
Provide Context to Foundation Model
      ↓
Generate Answer
```

Unlike relying only on the model's existing knowledge, RAG allows the application to retrieve information from an organization's knowledge base.

```text
        ↓

```

### Document Chunking

Large documents are divided into smaller pieces called **chunks**.

```text
Large Document
      ↓
┌─────────────┐
│   Chunk 1   │
├─────────────┤
│   Chunk 2   │
├─────────────┤
│   Chunk 3   │
└─────────────┘
```

### Embeddings

Chunks can be converted into **embeddings**, which are numerical representations that allow semantic similarity to be determined.

```text
Text Chunk
    ↓
Embedding Model
    ↓
Vector
```

### Vector Store

The generated vectors are stored in a **vector store**, which allows the system to search for information that is semantically relevant to a user's question.

```text
User Question
      ↓
Semantic Search
      ↓
Vector Store
      ↓
Relevant Chunks
```

## Quick Revision

> **Use Case:** Sales representatives need quick and reliable access to historical and current sales information.

> **Goal:** Build an Enterprise Knowledge Assistant that can retrieve relevant enterprise information and provide useful answers.

> **RAG:** Retrieves relevant external knowledge and provides it as context to a foundation model.

> **Chunking:** Splits large documents into smaller pieces.

> **Embeddings:** Converts information into numerical vector representations.

> **Vector Store:** Stores embeddings and enables semantic retrieval.

> **Foundation Model:** Uses the retrieved context to generate the final response.
