# AWS Region, Availability Zone & Data Center

## 1. AWS Region

A **Region** is a geographical location where AWS has its cloud infrastructure.

### Examples

```text
us-east-1 → N. Virginia
us-west-2 → Oregon
```

A Region contains **multiple Availability Zones (AZs)**.

---

## 2. Availability Zone (AZ)

An **Availability Zone** is an **isolated infrastructure location within an AWS Region**.

```text
Region
├── AZ-A
├── AZ-B
└── AZ-C
```

Multiple AZs provide:

* **High Availability**
* **Fault Tolerance**
* **Resilience**

If one AZ has an issue, applications running in another AZ can continue operating.

---

## 3. Data Center

A **Data Center** is a **physical facility** containing AWS infrastructure such as:

* Servers
* Storage
* Networking
* Power
* Cooling

An Availability Zone can contain **one or more data centers**.

```text
Region
│
├── AZ-A
│    ├── Data Center
│    └── Data Center
│
├── AZ-B
│    └── Data Center
│
└── AZ-C
     └── Data Center
```

---

## 4. Relationship

Each Region contains three or more Availability Zones (AZs). Each AZ consists of one or more discrete data centers with redundant power, networking, and connectivity.

```text
AWS Region
    ↓
Availability Zones
    ↓
Data Centers
    ↓
Servers / Storage / Networking
```

### Hierarchy

**Region → AZ → Data Center → Physical Infrastructure**

---

## 5. Quick Revision

| Term                       | Meaning                                          |
| -------------------------- | ------------------------------------------------ |
| **Region**                 | Geographic area containing AWS infrastructure    |
| **Availability Zone (AZ)** | Isolated infrastructure location within a Region |
| **Data Center**            | Physical facility containing AWS infrastructure  |

---

## Easy Memory Trick

> **Region = Geographic location**
> **AZ = Isolated location inside a Region**
> **Data Center = Physical facility**

### Interview Point

> **A Region consists of multiple isolated Availability Zones, and each Availability Zone can contain one or more data centers.**
