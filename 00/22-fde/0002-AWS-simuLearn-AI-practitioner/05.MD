# AWS SimuLearn — GenAI Webpage on EC2

## Use Case

A **marketing team** needs to maintain a web server used to share content with external clients.

### Problem

The team spends significant **time and effort updating web content and code**.

They want:

* Easier web content updates
* Less manual coding effort
* A user-friendly approach
* Employees with minimal AWS expertise to make updates
* To leverage **Generative AI**

---

## Solution / Exercise

Using **Amazon Bedrock Playground**, we used Generative AI to help **create a webpage**.

The generated webpage was then **hosted on an Amazon EC2 instance**.

### High-Level Flow

```text
User Requirement
      ↓
Amazon Bedrock Playground
      ↓
Generative AI
      ↓
Generate Webpage / Code
      ↓
EC2 Instance
      ↓
Web Server
      ↓
Webpage
```

---

## Services Used

| AWS Service                   | Purpose                                               |
| ----------------------------- | ----------------------------------------------------- |
| **Amazon Bedrock Playground** | Generate and experiment with webpage/code using GenAI |
| **Amazon EC2**                | Host the generated webpage                            |
| **Web Server**                | Serve the webpage to users                            |

---

## Key Learning

This exercise demonstrates how **Generative AI can reduce manual development effort**.

Instead of manually creating all webpage code, an employee can use a **Bedrock Playground to generate or modify content/code**, then deploy it to an EC2-hosted web server.

```text
Generative AI
      ↓
Faster Content / Code Creation
      ↓
Deploy to EC2
      ↓
Accessible Web Application
```

## AWS SimuLearn

**AWS SimuLearn** provides scenario-based, hands-on learning using realistic business problems.

The typical flow is:

```text
Business Scenario
      ↓
Design Solution
      ↓
Discuss Solution with AI
      ↓
Build Solution in AWS Console
      ↓
Validate Solution
```

It combines **Generative AI-based simulation** with **hands-on AWS Console exercises**.
