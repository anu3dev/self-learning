# Amazon EC2 — Quick Revision

## What is EC2?

**Amazon EC2 (Elastic Compute Cloud)** provides resizable virtual servers in the AWS Cloud.

Instead of purchasing physical servers, we can create and manage virtual servers called **EC2 Instances**.

---

## EC2 Instance

An **EC2 Instance** is a virtual server running in AWS.

```text
AWS Region
   │
   └── Availability Zone
          │
          └── EC2 Instance
                 ├── OS
                 ├── CPU
                 ├── Memory
                 ├── Storage
                 └── Network
```

---

## Key EC2 Concepts

### 1. AMI — Amazon Machine Image

An **AMI** is a template used to launch an EC2 instance.

It contains information such as:

* Operating system
* Software
* Configuration
* Root volume configuration

Examples:

```text
Amazon Linux
Ubuntu
Windows Server
```

---

### 2. Instance Type

The **instance type** determines the compute resources available to the instance.

It controls things such as:

* CPU
* Memory
* Network performance

Example:

```text
t3.micro
```

---

### 3. Key Pair

A **Key Pair** is used to securely connect to an EC2 instance.

For Linux instances, the private key is commonly used for **SSH** access.

```text
Your Computer
     │
     │ SSH + Private Key
     ↓
EC2 Instance
```

**Important:** Keep the private key secure.

---

### 4. Security Group

A **Security Group** acts as a virtual firewall for an EC2 instance.

It controls:

* **Inbound traffic** → Who can connect to the instance
* **Outbound traffic** → Where the instance can connect

Example:

```text
Inbound
22  → SSH
80  → HTTP
443 → HTTPS
```

Security Groups are associated with the **EC2 instance/network interface**.

---

## EC2 Lifecycle

An EC2 instance can move through different states:

```text
Launch
  ↓
Running
  ↓
Stop ─────→ Start
  ↓
Terminate
```

### Stop

The instance is stopped and can generally be started again later.

### Terminate

The instance is permanently deleted and cannot normally be restarted.

---

## Public IP

A public IP allows an EC2 instance to communicate with the internet.

Example:

```text
Internet
    ↓
Public IP
    ↓
EC2 Instance
```

A regular public IPv4 address can change when the instance is stopped and started.

For a persistent public IPv4 address, AWS provides an **Elastic IP**.

---

## Storage

EC2 commonly uses **Amazon EBS (Elastic Block Store)** for persistent block storage.

```text
EC2 Instance
     │
     └── EBS Volume
            └── Data
```

EBS volumes can persist independently of the EC2 instance lifecycle depending on their configuration.

---

## Basic EC2 Launch Flow

```text
1. Choose AMI
      ↓
2. Choose Instance Type
      ↓
3. Configure Instance
      ↓
4. Configure Storage
      ↓
5. Configure Security Group
      ↓
6. Select/Create Key Pair
      ↓
7. Launch Instance
      ↓
8. Connect to Instance
```
