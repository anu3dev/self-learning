# Amazon Bedrock Guardrails — Step 1

## What is Amazon Bedrock Guardrails?

**Amazon Bedrock Guardrails** helps control and filter interactions between users and foundation models.

It can be used to evaluate model interactions and prevent unwanted or sensitive content from reaching the user.

---

## High-Level Flow

```text
User
  ↓
User Input
  ↓
Foundation Model Inference
  ↓
FM Output
  ↓
Amazon Bedrock Guardrails
  ↓
Final Response
  ↓
User
```

The **Amazon Bedrock Guardrails** layer evaluates the model interaction before the final response is returned to the user.

---

## Guardrail Controls

The lab identifies four controls:

| Guardrail Control | Purpose |
|---|---|
| **Denied Topics** | Prevent specific topics from being handled |
| **Content Filters** | Filter unwanted or unsafe content |
| **PII Redaction** | Redact Personally Identifiable Information |
| **Word Filter** | Filter specified words |

---

## Flow

```text
User Input

    ├── Content Filters
```

The guardrail checks the model interaction before the **final response** is delivered to the user.
