# AWS SimuLearn — Build and Understand Code with Amazon Q

## Use Case

A children's educational publishing company wants to create an **automated story generation system** that produces personalized short stories based on user inputs such as:

- Character names
- Themes
- Settings

### Problem

The company wants to automate story generation while allowing developers to build and understand the underlying code.

The solution should:

- Accept user inputs
- Generate personalized stories using Generative AI
- Store generated stories
- Help developers understand and generate the required code

---

## Solution / Exercise

The solution uses **Amazon Q Developer** to help a novice programmer understand and generate code for the application.

The application uses an **AWS Lambda function** that makes an API call to **Amazon Bedrock** to generate the story.

The generated story is then stored in:

- **Amazon S3**
- **Amazon DynamoDB**

### High-Level Flow

```text
Novice Programmer
       ↓
Amazon Q Developer
       ↓
Understand / Generate Code
       ↓
AWS Lambda
       ↓
Lambda Function
(story-teller)
       ↓
Amazon Bedrock
       ↓
Foundation Model
       ↓
Generated Story
       ↓
┌───────────────┬────────────────┐
↓               ↓
Amazon S3       DynamoDB
Story Storage   Story Data
```

## Amazon Q Developer

**Amazon Q Developer** is used as an AI-powered coding assistant.

In this exercise, a novice programmer uses Amazon Q Developer to:

- Understand code
- Generate code
- Get inline code suggestions
- Build the Lambda function
- Work with the AWS services used by the application

### Development Flow

```text
Novice Programmer
       ↓
Amazon Q Developer
       ↓
Code Suggestions / Assistance
       ↓
AWS Lambda Function
       ↓
Amazon Bedrock API Call
```

The exercise demonstrates how an AI coding assistant can help developers build AWS applications even when they have limited programming experience.

## AWS Lambda

The Lambda function acts as the **story-generation application logic**.

```text
User Input
    ↓
Lambda Function
    ↓
Amazon Bedrock
    ↓
Generated Story
```

The Lambda function makes an API call to Amazon Bedrock to generate the personalized story.

The diagram identifies the Lambda function as:

```text
story-teller
```

---

## Amazon Bedrock

**Amazon Bedrock** provides access to foundation models that can generate the personalized story.

```text
Lambda
  ↓
Amazon Bedrock
  ↓
Foundation Model
  ↓
Generated Story
```

The application sends the required story information to the model, such as the character, theme, and setting.

## Storing the Generated Story

After the story is generated, the Lambda function stores the data in AWS services.

### Amazon S3

The generated story is stored in an **S3 bucket**.

```text
Generated Story
      ↓

      ↓
Amazon S3
(story-teller bucket)
```

### Amazon DynamoDB

The Lambda function also stores story-related data in a **DynamoDB table**.

```text
Generated Story / Data
        ↓
     Lambda
        ↓
    DynamoDB
   (story-table)
```

## Key Learning

This SimuLearn exercise demonstrates two important concepts:

**Amazon Q Developer** can assist developers with:

```text
Understand Code
      ↓
Generate Code
      ↓
Inline Suggestions
      ↓

```

### 2. Generative AI Application

A Lambda-based application can call **Amazon Bedrock** to generate content.

```text
Application
    ↓
Lambda
    ↓
Bedrock
    ↓
Foundation Model
    ↓
Generated Content
```

The generated content can then be persisted using services such as **S3 and DynamoDB**.
