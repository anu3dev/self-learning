# What is Amazon S3?

**Amazon S3 (Simple Storage Service)** is an AWS **object storage service** used to store and retrieve data.

---

## Core Concepts

| Concept | Meaning |
|---|---|
| **Bucket** | Container used to store objects |
| **Object** | Actual file/data stored in S3 |
| **Object Key** | Name/path used to identify an object |
| **GET** | Retrieve an object |
| **PUT** | Upload an object |
| **DELETE** | Delete an object |
| **Bucket Policy** | Resource-based policy controlling bucket access |
| **IAM** | Controls permissions for users, roles, and services |
| **Versioning** | Keeps multiple versions of an object |
| **Encryption** | Protects stored data |

---

## Basic Flow

```text
Application
     ↓
S3 API Request
     ↓
Authorization
     ↓
S3 Bucket
     ↓
S3 Object
```
