# AWS AI-Powered Agentic Services — Revision Notes

## 1. AWS Transform

**AWS Transform** is an **agentic AI-powered service** designed to accelerate and automate the **modernization and migration** of legacy workloads to AWS.

### What can AWS Transform modernize?

* **Legacy applications**
* **Databases**
* **Infrastructure**
* **Windows/.NET applications**
* **Mainframe workloads**

### Key Benefits

* Can accelerate **full-stack Windows/.NET modernization by up to 5×**
* Can reduce **mainframe modernization timelines from years to months**
* Automates significant portions of the modernization/migration process.

### Exam Keyword

> **AWS Transform = Modernize + Migrate legacy workloads to AWS**

Think:

**Legacy → Analyze → Transform/Modernize → AWS**

# 2. AWS Security Agent

**AWS Security Agent** is an **AI-powered security agent** that proactively secures applications throughout the **software development lifecycle (SDLC)**.

### What does it do?

It can assist with security activities such as:

1. **Design review**
2. **Code scanning**
3. **On-demand penetration testing**

### Key Characteristic

AWS Security Agent is designed to operate with the speed and scale of AI while achieving precision comparable to human penetration testers.

### Exam Keyword

> **AWS Security Agent = Application Security throughout the SDLC**

Think:

**Design → Code → Test → Secure**

# 3. AWS DevOps Agent

**AWS DevOps Agent** is an **advanced AI agent** that acts like an **always-on, experienced DevOps/SRE engineer**.

It autonomously helps investigate incidents, develop mitigation plans, and prevent future incidents.

### Important

AWS DevOps Agent is **NOT a monitoring tool**.

Instead, it works **with existing monitoring and observability tools**.

It can operate across:

* AWS environments
* Multicloud environments
* On-premises environments

### Three Main Capabilities

#### 1. Autonomous Incident Response

Automatically investigates production incidents and helps determine how to mitigate them.

#### 2. Proactive Incident Prevention

Identifies patterns and recommends actions to help prevent similar incidents in the future.

#### 3. On-Demand SRE Tasks

Can perform DevOps/SRE investigations and tasks when engineers need assistance.

---

# AWS DevOps Agent — 5-Step Process

Remember:

**Trigger → Investigate → Root Cause → Mitigate → Learn**

### 1. Trigger

An incident or alert occurs.

Example:

> Application latency suddenly increases.

### 2. Investigate

The agent investigates available telemetry, logs, metrics, traces, deployments, and other relevant information.

### 3. Root Cause

The agent determines the likely **root cause** of the incident.

### 4. Mitigate

It provides or executes appropriate **mitigation actions**, depending on the configured capabilities and permissions.

### 5. Learn

It learns from the incident and identifies ways to **prevent similar incidents in the future**.

# AWS DevOps Agent — Exam Trap

### ❌ Incorrect

> AWS DevOps Agent replaces Datadog/CloudWatch/other monitoring tools.

### ✅ Correct

> AWS DevOps Agent **works with existing monitoring and observability tools** to investigate and resolve operational issues.

So if a question says:

> "Replace the customer's existing monitoring solution"

**→ NOT the primary purpose of AWS DevOps Agent.**
